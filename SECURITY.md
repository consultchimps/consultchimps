# Security policy

## Supported versions

Until the first stable release, security fixes are applied to the latest
released version.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature. Do not open a
public issue containing exploit details, credentials, confidential documents, or
client data.

The project processes potentially sensitive business files. Reports involving
path traversal, unsafe overwrites, formula injection, archive extraction, or
unintended network access are especially valuable.
