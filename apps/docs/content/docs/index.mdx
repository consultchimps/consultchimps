ConsultChimps turns recurring document and data chores into deterministic tools.
Use the [online tools](/tools) when a file is already in front of you, the
command-line interface when you need an answer now, or the focused TypeScript
packages when you are building a repeatable workflow. The browser tools are
built from the same operation code as the CLI and libraries; a few defaults
differ by design and are called out in each tool's guide, and the remaining
operations run through the command line and libraries only.

<Callout title="Built for client work">
  Inputs are immutable by default, outputs include provenance, and the core
  operations do not require a hosted service.
</Callout>

## The operating model

Every operation returns the same result shape:

```ts
interface OperationResult {
  operation: string;
  artifacts: Array<{
    kind: "file" | "directory";
    path: string;
    mediaType?: string;
  }>;
  warnings: string[];
  metrics: Record<string, number>;
}
```

Normal terminal output turns that result into a detailed explanation for a
non-technical reader. It explains what happened, translates counts into plain
language, lists every created file, calls out warnings, confirms source-file
safety, and suggests what to do next. Automations can use `--json` to receive
the stable result shape directly.

## Design principles

- **Local-first:** client files remain on the machine running the operation.
- **Immutable inputs:** the toolkit refuses to overwrite source files.
- **Composable modules:** each capability is useful without the CLI.
- **Explicit provenance:** consolidated rows can retain file, sheet, and row.
- **Plain-language guidance:** every CLI tool explains its results and next
  steps without assuming technical knowledge.
- **Replaceable intelligence:** future OCR or AI providers remain optional.
