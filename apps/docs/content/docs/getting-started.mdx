## Requirements

- Node.js 24

## Try the CLI

Run a command without keeping a global installation:

```bash
npx consultchimps@latest --help
```

For regular terminal use, install the executable globally:

```bash
npm install --global consultchimps
consultchimps --help
```

For a repository-local CLI version, install it as a development dependency:

```bash
npm install --save-dev consultchimps
npx consultchimps --help
```

## Install a library

Install the narrowest package that owns the operation you need:

```bash
npm install @consultchimps/xlsx
```

```ts
import { consolidateWorkbooks } from "@consultchimps/xlsx";

const result = await consolidateWorkbooks(
  ["inputs/january.xlsx", "inputs/february.xlsx"],
  "outputs/consolidated.xlsx",
);
```

The adapter package declares its required ConsultChimps packages, so npm
installs `core`, `files`, and `tabular` automatically. Use `@consultchimps/pdf`
for PDF operations or `@consultchimps/pptx` for PowerPoint template operations.

## Install the workspace

```bash
git clone https://github.com/rashoodz/consultchimps.git
cd consultchimps
pnpm install
pnpm build
```

## Choose your first operation

Every shipped operation has a complete guide:

- [Consolidate spreadsheets](./tools/spreadsheets)
- [Split a spreadsheet](./tools/spreadsheet-split)
- [Populate a PowerPoint template](./tools/powerpoint-populate)
- [Split a PDF](./tools/pdf-split)
- [Merge PDFs](./tools/pdf-merge)

For example, split a PDF into individual pages:

```bash
pnpm consultchimps pdf split report.pdf --output outputs/report-pages
```

The CLI refuses to replace existing output files unless you explicitly pass
`--force`.

To create a presentation from a designed slide and Excel records:

```bash
pnpm consultchimps pptx populate \
  --template profile-template.pptx \
  --data profiles.xlsx \
  --sheet Profiles \
  --template-slide 2 \
  --output outputs/company-profiles.pptx
```

## Open the documentation locally

```bash
pnpm docs:dev
```

Then open [http://localhost:3000](http://localhost:3000).

## Machine-readable output

Add the global `--json` option before a command when another process will
consume the result:

```bash
pnpm consultchimps --json pdf merge "inputs/**/*.pdf" \
  --output outputs/combined.pdf
```

Successful operations return their artifacts, warnings, and metrics as JSON.
Known ConsultChimps errors include a stable error code and structured details.
