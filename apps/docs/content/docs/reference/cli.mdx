## Global options

```text
consultchimps [options] [command]

Options:
  -V, --version   output the version number
  --json          print structured JSON instead of the detailed explanation
  -h, --help      display help
```

Place `--json` before the subcommand:

```bash
consultchimps --json pdf split report.pdf
```

## Human-readable output

Normal commands are intentionally detailed for non-technical users. A successful
operation explains:

1. What ConsultChimps did.
2. What each result count means.
3. Every file that was created.
4. Whether any warnings occurred.
5. Whether the source files were left unchanged.
6. What the user can do next.

Recoverable errors explain what went wrong, suggest safe recovery steps, and
include a stable error reference that can be shared with support. Use `--json`
to replace these explanations with the compact structured result needed by an
automation.

## Spreadsheet consolidation

```text
consultchimps sheets consolidate [options] <inputs...>

Required:
  -o, --output <path>       output .xlsx file

Options:
  --sheet <names...>        include only these worksheet names
  --header-row <number>     one-based header row
  --hidden                  include hidden worksheets
  --no-source               omit file, sheet, and row provenance
  --output-sheet <name>     output worksheet name (default: Consolidated)
  -f, --force               replace an existing output file
```

## Spreadsheet splitting

```text
consultchimps sheets split [options] <input>

Required:
  -c, --column <name>       column header used to split rows

Options:
  -o, --output <directory>  output directory (default: <input>-split)
  --sheet <name>            worksheet to split
  --table <name>            named Excel Table to split instead of the used range
  --header-row <number>     one-based header row
  --hidden                  allow a selected hidden worksheet
  --preserve-workbook       retain the complete workbook and filter only the table
  --skip-blank              omit rows whose split-column value is blank
  --prefix <name>           output filename prefix
  -f, --force               replace existing output files
```

`--table` limits input to an Excel structured table and ignores cells outside
its range. Because the table defines its own headers, it cannot be combined with
`--header-row`. Add `--preserve-workbook` to keep every worksheet and the source
formatting while replacing only the selected table's data rows. The preservation
option requires `--table`.

## PDF splitting

```text
consultchimps pdf split [options] <input>

Options:
  -o, --output <directory>  output directory
  --prefix <name>           output filename prefix
  -f, --force               replace existing output files
```

## PowerPoint template inspection

```text
consultchimps pptx inspect-template [options] <template>

Options:
  --template-slide <number>  one-based template slide (default: 1)
```

The report lists valid placeholder names and occurrence counts, malformed
placeholder locations, and unsupported placements. Split-run placeholders are
supported.

## PowerPoint template population

```text
consultchimps pptx populate [options]

Required:
  --template <path>          source .pptx template
  --data <path>              source .xlsx workbook
  -o, --output <path>        output .pptx presentation

Options:
  --sheet <name>             worksheet containing the records (default: first)
  --template-slide <number>  one-based template slide (default: 1)
  --header-row <number>      one-based row containing field names
  -f, --force                replace an existing output presentation
```

Place the global `--json` option before `pptx` to receive the structured
inspection or operation result.

## PDF merging

```text
consultchimps pdf merge [options] <inputs...>

Required:
  -o, --output <path>       output PDF file

Options:
  -f, --force               replace an existing output file
```

## Exit behavior

Successful commands exit with status `0`. Invalid input, discovery failures,
unreadable documents, and output-safety failures set exit status `1` and write a
detailed explanation to standard error.
