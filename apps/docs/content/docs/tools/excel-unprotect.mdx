# Excel unprotect

[Use this tool in your browser](/tools/excel-unprotect). Processing stays on
your machine; nothing is uploaded and the original workbook is not changed.

The tool removes ordinary worksheet (`sheetProtection`) and workbook-structure
(`workbookProtection`) protection from `.xlsx` and `.xlsm` OOXML workbooks
without needing the protection password. Formulas, formatting, hidden sheets,
metadata, relationships, and VBA content are preserved as package parts.

Office files encrypted or password-required to open are not supported. This is
not password cracking or encryption bypass.

```bash
consultchimps sheets unprotect protected.xlsx --output unprotected.xlsx
```
