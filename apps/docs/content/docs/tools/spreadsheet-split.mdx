---
title: Split a workbook by column
description:
  Create one Excel workbook for every distinct value in a selected column.
icon: Rows3
---

The spreadsheet splitter reads one worksheet as a table, groups its rows by a
column, and writes each group to a separate `.xlsx` file. The source workbook is
never modified.

## Basic usage

```bash
pnpm consultchimps sheets split clients.xlsx \
  --column Region \
  --output outputs/by-region
```

For a workbook containing `North`, `South`, and blank values in `Region`, the
default output names are:

```text
clients-North.xlsx
clients-South.xlsx
clients-blank.xlsx
```

Each output contains the original headers, only the matching rows, an
autofilter, and practical column widths.

## Choose the worksheet and header

When a workbook has more than one visible, non-empty worksheet, select the
source explicitly:

```bash
pnpm consultchimps sheets split clients.xlsx \
  --sheet "Active clients" \
  --column Region \
  --header-row 3 \
  --output outputs/by-region
```

Worksheet and column matching ignore letter case. `--header-row` is one-based,
matching the row number displayed by Excel. Add `--hidden` when intentionally
selecting a hidden worksheet.

## Use a named Excel Table (preferred)

If the worksheet contains titles, notes, formulas, or multiple data blocks,
split a named Excel Table instead of treating the worksheet's complete used
range as one table. A structured table is the most reliable data source: it
defines its own headers and boundaries, so nothing outside it can leak into the
outputs.

```bash
pnpm consultchimps sheets split clients.xlsx \
  --table ClientData \
  --column Region \
  --output outputs/by-region
```

Table-name matching ignores letter case. The splitter reads only the structured
table's columns and data rows, excludes its totals row, and ignores every cell
outside the table range.

Excel Tables define their own headers, so `--header-row` cannot be combined with
`--table`. You may add `--sheet` as an extra worksheet constraint, and
`--hidden` is still required when the selected table is on a hidden worksheet.

### Preserve the complete workbook

Splitting an Excel Table keeps the complete workbook by default: each output is
a full copy of the source file in which only the selected table changed.
Original worksheets, styles, merged cells, column widths, notes, cover sheets,
and content outside the table all carry over. Matching rows are compacted at the
top of the table's data area, its totals row is moved when present, and its
structured range is resized to the matching rows.

<Callout title="Pro tip: prepare the workbook before splitting">
  Because every output is a copy of the file you saved, prepare the workbook
  exactly as you want to deliver it before running the split: set the zoom you
  want on each sheet, place the selector on cell **A1** so every file opens
  consistently, add the cover sheet where needed, and save the document. Every
  generated workbook will open just like your prepared original.
</Callout>

Add `--no-preserve-workbook` when you want compact, data-only outputs containing
just the selected headers and matching rows:

```bash
pnpm consultchimps sheets split clients.xlsx \
  --table ClientData \
  --column Region \
  --no-preserve-workbook \
  --output outputs/by-region
```

Preserving the workbook requires `--table`; it is not available for named ranges
or for splitting a worksheet's complete used range.

## Use a named range

When the data is not formatted as an Excel Table but a workbook-level named
range covers it, select the range by name. The range's first row provides the
headers, and cells outside the range are ignored:

```bash
pnpm consultchimps sheets split clients.xlsx \
  --range ClientRange \
  --column Region \
  --output outputs/by-region
```

Range-name matching ignores letter case, and Excel's built-in names such as
print areas are never considered. `--range` cannot be combined with `--table` or
`--header-row`, and named-range splits always produce compact data-only outputs.

Prefer sources in this order: a named Excel Table, then a named range, then the
worksheet's complete used range.

## Blank values

Blank cells are included by default in a `blank` workbook so rows are not
silently discarded. Omit them explicitly when needed:

```bash
pnpm consultchimps sheets split clients.xlsx \
  --column Region \
  --skip-blank
```

The structured result reports the number of skipped rows, and the human-readable
output prints a warning.

## Safe filenames

Output files use the source workbook name as their prefix. Override it with
`--prefix`:

```bash
pnpm consultchimps sheets split clients.xlsx \
  --column Region \
  --prefix "client-region"
```

Characters that are unsafe on common filesystems are replaced with hyphens. When
two distinct values produce the same safe filename, the later file gains a
numeric suffix such as `client-region-North-West-2.xlsx`.

Numbers, text, and booleans remain distinct groups even when their displayed
text is the same. Group order follows the first appearance of each value in the
worksheet.

## Output safety

The operation checks every destination before writing any workbook. It stops if
an output already exists:

```bash
pnpm consultchimps sheets split clients.xlsx \
  --column Region \
  --output outputs/by-region \
  --force
```

Use `--force` only when replacing the complete output set is intentional.

## TypeScript API

```ts
import {
  planSplitWorkbookByColumn,
  splitWorkbookByColumn,
} from "@consultchimps/xlsx";

const plan = await planSplitWorkbookByColumn({
  input: "clients.xlsx",
  outputDirectory: "outputs/by-region",
  column: "Region",
  table: "ClientData",
});
console.log(plan.outputs.map((output) => output.path));

const result = await splitWorkbookByColumn({
  input: "clients.xlsx",
  outputDirectory: "outputs/by-region",
  column: "Region",
  filenamePrefix: "client-region",
  includeBlank: true,
  table: "ClientData",
});

console.log(result.metrics.outputFiles);
```

Table splits preserve the workbook unless `preserveWorkbook: false` is passed;
use `range` instead of `table` to select a named range. The format-neutral
grouping primitive is also available from `@consultchimps/tabular` as
`groupTableByColumn`. Use `readWorkbookExcelTables` or `readWorkbookNamedRanges`
from `@consultchimps/xlsx` when an application needs to inspect the available
data sources before choosing one.
